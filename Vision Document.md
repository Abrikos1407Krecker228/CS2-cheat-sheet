# CS2-cheat-sheet
Проект по разработке сайта с раскидками гранат для Counter-Strike 2.
## Цель
- Создать удобный каталог для популярных карт.
- Пройти полный цикл разработки SDLC по методологии Waterfall.
- Изучить как работает на практике весь стек, который будет использован.
- Получить артефакты QA и аналитика.
## Проблема
Этот продукт решает проблему игроков когда во время соревновательного матча или тренировки проблематично найти или вспомнить лайнап, необходимый для корректного броска гранаты. 
- В соревоновательной игре нет времени на поиск гайдов
- Лайнапы разрознены (Youtube, tikTok и т.д.)
- Нет быстрого доступа по фильтрам поиска (Карта, позиция..)
## Решение
Создать каталог раскидок с фильтрацией по картам и типам гранат, что позволит быстро найти короткий гайд как правильно действовать.
## Целевая аудитория
Игроки Counter-Strike 2: от новичков, изучающих базовые раскидки, до профессионалов, соревнующихся на платформе Faceit
## MVP (Minimum Viable Product)
- Сайт может открыть любой человек с ПК
- Фильтрация по карте и типу гранаты
- Наличие видео-инструкций
## Не входит в MVP 
- Авторизация
- Мобильные устройства
- Система оценок
- Загрузка контента от пользователей
