# CS2-cheat-sheet
Проект по разработке сайта с раскидками гранат для Counter-Strike 2.
## Цель
- Создать удобный веб-каталог для соревновательных карт.
- Изучить и применить HTML, CSS и JavaScript — базовые технологии, из которых строится любая современная веб-страница.
- Изучить учебные материалы Mozilla Developer Network (MDN) по веб-разработке:
- https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started
- Разработать первую рабочую версию продукта (MVP).
## Проблема
Этот продукт решает проблему игроков, которым во время соревновательного матча или тренировки проблематично найти или вспомнить лайнап, необходимый для корректного броска гранаты. 
- В соревновательной игре нет времени на поиск гайдов.
- Лайнапы разрознены (Youtube, tiktok и т.д.)
- Отсутствует удобный единый каталог с возможностью фильтрации по карте, позиции и типу гранаты.
## Решение
Создать каталог раскидок с фильтрацией по картам, пизициям и типам гранат. Каждая раскидка будет содержать краткую инструкцию, позволяющую игроку быстро ознакомиться с необходимой информацией и повторить бросок.
## Целевая аудитория
- Игроки Counter-Strike 2: от новичков, изучающих базовые раскидки, до профессионалов, соревнующихся на платформе Faceit
- Люди, которым интересна web-разработка и схожие профессии
## MVP (Minimum Viable Product)
- Сайт может открыть любой желающий
- Наличие видеоинструкций
- Наличие системы поиска и фильтрации по карте, позиции и типу гранаты.
- Видеоматериалы предоставляются только для дымовых гранат (Smoke).
- Для остальных типов гранат могут использоваться только текстовые инструкции.
- Список карт соответствует пулу карт турнира PGL Major Singapore 2026
## Не входит в MVP 
- Наличие большого объёма документации, характерный для коммерческих it-продуктов, допустима имитация в v1(первой версии) сайта
- Система авторизации и регистрации
- Система оценок и отзывов
- Поддержка мобильных устройств
- Загрузка контента пользователями
## Критерий успеха
- Выполнены требования MVP
