## Общая информация
- Название проекта - CS2 Cheat Sheet
- Описание продукта - CS2 Cheat Sheet это веб-приложение для быстрого поиска лайнапов гранат в Counter-Strike 2 с использованием фильтрации по картам и типам гранат.
- Цель документа - определить функциональные требования к веб-приложению CS2 Cheat Sheet
## Функциональные требования

*Формат: ФТ_БТ_xx*

**ФТ_01.** 
  - ФТ_01_01. Система должна отображать главную страницу с приветствием и инструментами поиска лайнапов.
  - ФТ_01_02. В системе три фильтра для поиска: карта, тип гранаты, место падения.

  ~~- ФТ_01_03. Для получения инструкции пользователь должен выполнить не более 8 кликов от открытия сайта.~~
  
  ~~- ФТ_01_04. Система должна отображать результаты поиска не позднее 3 секунд после выбора параметров фильтрации.~~
  
**ФТ_02.**
  - ФТ_02_01. Система сначала должна предоставить фильтр для выбора карты и типа гранаты
  - ФТ_02_02. После указания карты и типа гранаты система должна предоставить фильтр для указания места падения гранаты.
  - ФТ_02_03. После заполения всех фильтров должна появиться видеоинструкция
  - ФТ_02_04. Одновременно с видеоинструкцией должно появиться текстовое описание
  - ФТ_02_05. Фильтр для выбора карты должен содержать:
    - Dust2
    - Mirage
    - Nuke
    - Ancient
    - Inferno
    - Overpass
    - Anubis
    - Cache
  - ФТ_02_06. Фильтр для выбора типа гранаты должен содержать:
    - Smoke
    - Flashbang
    - Molotov
  - ФТ_02_07. Фильтр для места падания гранаты должен содержать русскоязычные общепринятые наименования, в зависимости от карты, согласно таблице

| Карта  | Позиция |
| ------------- | ------------- |
| Dust2 | Шорт, Мид, Двери, Окно |
| Mirage | Тикет, Джангл, Стерс, Коннектор, Окно, Шорт, Окно кухня |
| Nuke | Улица1 |
| Ancient  | Светлая, Тёмная, Рэд Рум, Девятка, Пончик, |
| Inferno  | Гробы, Лонг, Шорт |
| Overpass  | Банк, Мусорка, Хелпа, Девятка |
| Anubis  | Лонг, Темпл, Мид, Камера, Хэвен |
| Cache  | Коннектор |

  - ФТ_02_09. Если по выбранным параметрам лайнапы отсутствуют, система должна отображать сообщение "Лайнапы не найдены".

**ФТ_03.** 
  - ФТ_03_01. Место в котором система покажет инструкцию находится под фильтрами 
  - ФТ_03_02. Система показывает видео в результате поиска. Может показать текст

**ФТ_04.**
  - ФТ_04_01. Сайт можно найти через поиск в браузере
  - ФТ_04_02. Пользователь должен иметь возможность открыть главную страницу сайта по URL-адресу сайта.
  - ФТ_04_03. Пользователь попадает сразу на страницу с фильтрами
