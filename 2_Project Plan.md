# Project Plan - CS2 Cheat Sheet
## Роли и ответственность
В рамках проекта автор совмещает несколько ролей:
- Product Owner
- Fullstack Аналитик
- Разработчик
- Инженер по тестированию
## Требования MVP
- Доступ к сайту осуществляется через браузер на ПК
- Фильтрация по карте
- Фильтрация по типу гранаты
- Просмотр видео-инструкций
## Не входит в MVP
- Авторизация пользователей
- Поддержка мобильных устройств
- Наличие системы оценок и комментариев
- Загрузка контента от пользователями
## Этапы реализации
**1. Сбор и анализ требований**
- Составить документ Vision Document (Документ видения продукта)
- Составить артефакты Аналитика. *Здесь я выступаю в роли заказчика и аналитика*
- Бизнес-требования
- Функциональные требования
- Тест-кейсы
- Traceability Matrix (RTM)
**2. Проектирование**
- Структура сайта
- Wireframe страниц
- Структура данных лайнапов
- Технические решения и выбор стека
**3. Разработка**
- HTML разметка
- CSS стили
- JavaScript логика
- Репозиторий GIT (используется на всех этапах)
**4. Тестирование**
- Тест-план
- Чек-лист
- Тест-кейсы
- Баг-репорты
- Отчёт о результатах тестирования
## Критерий завершения проекта
Проект считается завершённым, если:
- Выполнены все требования MVP
- Критические баги устранены
- Написаны артефакты Аналитика и QA
- Проект опубликован в репозитории GitHub
- Основные пользовательские сценарии успешно пройдены
