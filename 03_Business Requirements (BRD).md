## Общая информация
- Название проекта - CS2 Cheat Sheet
- Описание продукта - CS2 Cheat Sheet это веб-приложение для быстрого поиска лайнапов гранат в Counter-Strike 2 с использованием фильтрации по картам и типам гранат.
- Цель документа - определить бизнес требования к веб-приложению CS2 Cheat Sheet
## Бизнес-требования
- БТ_01. Пользователь (игрок) должен иметь возможность быстро находить необходимые лайнапы.
- БТ_02. Сайт должен быть на русском языке
- БТ_03. Не должно быть регистрации
- БТ_04. Не должно быть рекламы
- БТ_05. Должно быть мниимальное количество текста на сайте
- БТ_06. Лайнапы должны быть актуальными
- БТ_07. Поиск лайнапов осуществялется по фильтрам: карта, вид гранаты, место падения
- БТ_08. Виды гранат: дым, флешка, молотов, хае
- БТ_09. Поддерживаемые карты(передовой): Dust2, Mirage, Nuke, Ancient, Inferno, Overpass, Anubis, Cache
- БТ_10. MVP является только возможность посмотреть лайнапы смоков на карте Mirage
- БТ_11. Место падения:

| Карта  | Позиция |
| ------------- | ------------- |
| Dust2 | Шорт, Мид, Двери, Окно |
| Mirage | Тикет, Джангл, Стерс, Коннектор, Окно, Шорт, Окно кухня |
| Nuke | Улица1 |
| Ancient  | Светлая, Тёмная, Рэд Рум, Девятка, Пончик, |
| Inferno  | Гробы, Лонг, Шорт |
| Overpass  | Банк, Мусорка, Хелпа, Девятка |
| Anubis  | Лонг, Темпл, Мид, Камера, Хэвен |
| Cache  | Коннектор |

- БТ_12. На сайте должна быть картинка с картами передовой и называниями позиций подписанными на них. В 2D стиле
- БТ_13. Сайт в минималистичном дизайне. Шапка - приветствие и описание сайта. Ниже поиск лайнапа - три фильтра: карта, тип гранаты, место падения. Снизу слева под фильтрами появляется видеоролик и правее находится текстовая мини-инструкция. В самом низу находится ссылка на Steam профиль.
- БТ_14. MVP является только возможность посмотреть лайнапы смоков на карте Mirage
- БТ_15. Ролик должен длиться от 8 до 15 секунд
- БТ_16. В мини-тексте подсказке ниже должна быть картинка как граната реализовалась после броска.
- БТ_17. Поиск лайнапа от главной страницы не должен занимать больше 7 кликов.
- БТ_18. Видеоролик должен появится за менее 3 секунд.
- БТ_19. Сайт должен быть доступен из браузера в Steam Overlay
- БТ_20. Сайт должен поддерживать соотношение сторон монитора 4:3 и разрешение 1280×960 или 1280×1024 и 1920х1080
- БТ_21. Сайт должен поддерживать сайт Google Chrome - приоритете. Также Яндекс Браузер, Mozilla Firefox, Microsoft Edge, Opera.
- БТ_22. Игроки могут только смотреть предоставленный контент. Редактировать не могут. Это делаю разработчики
- БТ_23. Если нужной инструкции по поиску не существует в системе - вывести сообщение "Контент не создан".
- БТ_24. Сайт должен выдержать то что 1000 клиентов ищут видео.
- БТ_25. 50 клиентов одновременно смотрят видео.
- БТ_26. Главная страница открывается за менее 2 секунд.
- БТ_27. Видеоролики должны храниться на сервере или Youtube.
- БТ_28. Сайт должен открываться с ПК на ОС Windows 11.
- БТ_29. Название сайта - CS2-cheat-sheet.

## Критерии приёмки
1. Пользователь может найти необходимый лайнап смоков на карте Mirage.
2. Пользователь может просмотреть инструкцию по выполнению лайнапа.
