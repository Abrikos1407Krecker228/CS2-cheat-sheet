## Общая информация
- Название проекта - CS2 Cheat Sheet
- Описание продукта - CS2 Cheat Sheet это веб-приложение для быстрого поиска лайнапов гранат в Counter-Strike 2 с использованием фильтрации по картам и типам гранат.
- Цель документа - определить бизнес требования к веб-приложению CS2 Cheat Sheet

## Процесс получения функциональных требований
1. БТ_01. Пользователь должен иметь возможность быстро находить необходимые лайнапы.

За какое время и количество кликов система должна показать лайнапы?

- Сначала показывает лицевую часть сайта с необходимыми фильтрами для поиска.
- Пользователь нажимает поочерёдно на каждый фильтр и указывает переменную в нём. Карту, тип гранаты, место броска, место падения.
- От лицевой части сайта до видеоинструкции необходимо сделать 8 кликов.
- От указания переменных в фильтрах до появления на мониторе видеоинструкции должно пройти не более 3 секунд

2. БТ_02. Пользователь должен иметь возможность находить необходимые лайнапы с использованием инструментов поиска и фильтрации.

Как именно система поможет пользователю быстро находить лайнапы?

- Система первым покажет фильтр по карте. Далее появятся фильтры по: гранате, месту броска, месту падения. 
- Список карт соответствует актуальм картам, которые используются на официальных соревнованиях: Dust2, Mirage, Nuke, Ancient, Inferno, Overpass, Anubis, Cache.
- Список типов гранат ограничен теми, которые используются в лайнапах: дым, флеш, молотов.
- Фильтр по месту броска и месту падения соответствует русскоязычным общепринятым наименованиям:

| Карта  | Позиция |
| ------------- | ------------- |
| Dust2 | Шорт, Мид, Двери, Окно |
| Mirage | Тикет, Джангл, Стерс, Коннектор, Окно, Шорт, Окно кухня |
| Nuke | Улица1 |
| Ancient  | Светлая, Тёмная, Рэд Рум, Девятка, Пончик, |
| Inferno  | Гробы, Лонг, Шорт |
| Overpass  | Банк, Мусорка, Хелпа, Девятка |
| Anubis  | Лонг, Темпл, Мид, Камера, Хэвен |
| Cache  | Коннектор |

- По указанным фильтрам покажет от одного до нескольких видео и/или текстовых инструкций.

3. БТ_03. Пользователь должен иметь возможность просматривать инструкции по выполнению лайнапов (текст и/или видео).

Как выглядят инструкции?

- Инструкция повяляется на мониторе после указания переменных в фильтрах.
- Находится под фильтрами.
- Инструкция представляет собой короткий видео ролик, записанный в виртуальном мире игры.
- Дополнительно ниже может указываться текствое описание поледовательности действий и уточнения для корректного броска.

4. БТ_04. Пользователь должен иметь возможность использовать продукт без регистрации и авторизации.

Как это выглядит для пользователя?

- Пользователь открывает сайт через ссылку или через заголовок в поисковой выдаче браузера
- Пользователь попадает сразу на лицевую часть сайта
- Пользователь может взаимодействовать с фильтрами для поиска лайнапа сразу (без регистрации и авторизации)

5. БТ_05. Пользователь должен иметь доступ к ресурсу через веб-браузер на ПК.

Как пользователь может попасть на сайт?

- Пользователь должен использовать ПК, ноутбук и т.п.
- Пользователь должен иметь на своём устройстве операционную систему Windows.
- Пользователь должен использовать один из нескольких популярных браузеров: Google Chrome, Яндекс Браузер, Opera, Microsoft Edge, Mozilla Firefox.
- Пользователь может попасть на сайт из оверлея Steam.

6. БТ_06. Пользователь должен иметь возможность получать доступ к ресурсу без необходимости сворачивать игру.

Можно ли попасть на сайт не сворачивая игру?

- Пользователь может попасть на сайт из оверлея Steam.

8. БТ_08. Контент должен быть структурирован и понятен для пользователей различного уровня подготовки.

Что делать если новичок не знает названия позиций на картах?

- На сайте должна быть кнопка которая открывает рисунок карты с обозначениями позиций в соостветствии с указанной картой в фильтре 
- В этом случае рысунок карты распологается в правой части экрана. Видео распологается слева.
