## Общая информация
- Название проекта - CS2 Cheat Sheet
- Описание продукта - CS2 Cheat Sheet это веб-приложение для быстрого поиска лайнапов гранат в Counter-Strike 2 с использованием фильтрации по картам и типам гранат.
- Цель документа - определить бизнес требования к веб-приложению CS2 Cheat Sheet
## Бизнес-требования
БТ_01. Пользователь должен иметь возможность быстро находить необходимые лайнапы.

БТ_02. Пользователь должен иметь возможность находить необходимые лайнапы с использованием инструментов поиска и фильтрации.

БТ_03. Пользователь должен иметь возможность просматривать инструкции по выполнению лайнапов (текст и/или видео).

БТ_04. Пользователь должен иметь возможность использовать продукт без регистрации и авторизации.

БТ_05. Пользователь должен иметь доступ к ресурсу через веб-браузер на ПК.

БТ_06. Пользователь должен иметь возможность получать доступ к ресурсу без необходимости сворачивать игру.

~~БТ_07. Продукт должен обеспечивать быстрый доступ к информации во время матча или тренировки.~~

БТ_08. Контент должен быть структурирован и понятен для пользователей различного уровня подготовки.
## Ограничения
- Поддержка мобильных устройств не входит в MVP.
- Пользовательская загрузка контента не входит в MVP.
- Система рейтингов и комментариев не входит в MVP.
- Система авторизации пользователей не входит в MVP.
## Критерии приёмки
1. Пользователь может найти необходимый лайнап без использования сторонних ресурсов.
2. Пользователь может просмотреть инструкцию по выполнению лайнапа.
3. Все требования MVP реализованы.
